# Agent Context: GOVA iOS

You are the iOS lead for a GOVA app. A companion `gova-monolith` project owns
the Go backend and the JSON API; you build only the native SwiftUI client
against it.

`SEED.md`'s **Generated Context** is your source of truth for screens, models
and endpoints. `/export:mobile` writes it by transforming the web app's
committed `src/app/api.json`. Never edit it by hand — re-run the export.

The Xcode project is generated by XcodeGen: **after adding any Swift file, run
`xcodegen generate` inside `ios/`**, or the file is not in the project and the
build silently ignores it.

## Setup

Run `./install-claude.sh` once per clone — it sets `Config.plist`'s
`API_BASE_URL` and generates the Xcode project. Then `/prep` collects the app
name, gova-monolith path, API base URL and design notes, writes them into
`SEED.md`, and runs the export. Then `/build`.

## The wire contract

Everything the API guarantees is in the monolith's **`docs/API-CONTRACT.md`** —
the response envelope, the error codes, the date format, pagination, and the
manifest fields this repo reads. Read it rather than re-deriving anything.

Two consequences you will hit constantly:

- Every response is wrapped in `{"ok":…,"data":…,"error":…}`. `APIClient`
  unwraps it, so your `Codable` types describe the **`data` payload**, never the
  envelope.
- Timestamps are RFC3339 with no fractional seconds, which is exactly why
  `APIClient` uses `.iso8601`. A `timestamp` field is a `Date`.

Auth is always present — the monolith ships it. The bearer endpoints
(`login_token`, `logout_token`, `me_token`) always exist; there is nothing to
scaffold and no "is auth set up?" check to make.

## Translation guide

### Step 1 — Read the Generated Context

Confirm the screens listed, each model's fields and types, which endpoints each
screen uses, and whether auth is required. If the block is empty, STOP and tell
the developer to run `/prep`.

### Step 2 — Swift models

One struct per model in `ios/GovaApp/Models/`. `Codable`, `Identifiable`, `var
id: Int`, `CodingKeys` mapping snake_case to camelCase.

| Manifest type | Swift |
|---|---|
| string | `String` |
| int | `Int` |
| boolean | `Bool` |
| float | `Double` |
| timestamp | `Date` |

A nullable field is an optional — the manifest records nullability explicitly,
so you never need to read the SQL schema.

```swift
struct Item: Codable, Identifiable {
    let id: Int
    let name: String
    let createdAt: Date

    enum CodingKeys: String, CodingKey {
        case id, name
        case createdAt = "created_at"
    }
}
```

### Step 3 — Screens, driven by endpoint kinds

Generate exactly the screens a resource's **kinds** support. **Never invent an
operation the manifest does not expose.**

| Kind | Generate |
|---|---|
| `list` | list screen; `vm.load()` → `GET /api/v1/{plural}` |
| `detail` | detail screen reached by tapping a row; `vm.loadDetail(id)` |
| `create` | create `Form` in a `.sheet` from a `+` toolbar button, then reload |
| `update` | edit `Form` on the detail → `PUT`, then reload |
| `delete` | `.onDelete` swipe on the list, and/or a delete button on the detail |

**Field format → control.** A field carrying `[format: X]` gets the matching
control and write format — never a plain `TextField`:

| format | control | value sent |
|---|---|---|
| `datetime-local` | `DatePicker([.date, .hourAndMinute])` | `2026-07-27T11:45` — no seconds, no `Z` |
| `date` | `DatePicker(.date)` | `2026-07-27` |
| `time` | `DatePicker(.hourAndMinute)` | `11:45` |
| `email` | `TextField` + `.keyboardType(.emailAddress)` + no autocapitalization | the string |
| `json` | monospaced `TextEditor` | the raw JSON string |

A `datetime-local` field is a `String`, not a `Date` — distinct from a
`timestamp`, which is a `Date` with seconds and a zone.

**Children nest.** The **Relationships** section lists each child and its
foreign key. A child gets **no top-level screen**: its list renders inside the
parent's detail, loaded as `?filter={fk}:{parentId}`, and its create sheet
pre-fills the fk. Only resources with no `references` field become tabs — the
`Top-level list screens` line says which.

**Custom endpoints become actions.** Each `kind:custom` entry carries a
`summary`, its schemas, and `attach` + `control` hints. `control: button` → a
button that calls the endpoint and applies the response; `control: form` → a
`.sheet` with one control per request field. `attach: detail` puts it on the
detail screen, `attach: list` on the list toolbar. Call through
`APIClient.shared` per the endpoint's method.

**Per resource:**
- `ViewModels/NameViewModel.swift` — all fetch and mutation logic, `@Published`
  state (`items`, an optional `selected` if a `detail` kind exists, plus
  `isLoading` and `errorMessage`), one `async` method per available operation
- `Views/NameListView.swift`
- `Views/NameDetailView.swift` — only if a `detail` kind exists

Build the ViewModel first, then the View. Every ViewModel declares:

```swift
@Published var isLoading = false
@Published var errorMessage: String? = nil
```

and every View renders it when non-nil:

```swift
if let msg = viewModel.errorMessage {
    Text(msg).foregroundStyle(.red).font(.caption)
}
```

### Step 4 — Navigation

Wire `ContentView.swift` with `NavigationStack` destinations for each screen. If
auth is required, show `LoginView` when `auth.isLoggedIn == false`.

Give every `TabView` item, list row, and detail root a stable
`.accessibilityIdentifier` — the UI tests need them.

## Architecture rules (non-negotiable)

1. **MVVM.** No network calls in Views.
2. **`APIClient.shared` only.** Never raw `URLSession`.
3. **Keychain only.** Never a token in `UserDefaults` — `AuthManager` owns it.
4. **No force unwrap.** No `!` on optionals; use `guard let`.
5. **`@MainActor` on ViewModels.**
6. **async/await only.** No completion handlers.
7. **`NavigationStack`**, never the deprecated `NavigationView`.
8. **Every API call has a visible error state.**
9. **`Config.plist` for the base URL.** Never hardcode it.
10. **`xcodegen generate` after adding any file.**

## Pre-committed infrastructure

`ios/GovaApp/Lib/` is hand-written and shared. **Never regenerate these** —
import and use them.

- **`APIClient.swift`** — `shared`, reads `API_BASE_URL` from `Config.plist`,
  injects `Authorization: Bearer` when `AuthManager` holds a token, unwraps the
  envelope. `get`/`post`/`put`/`delete` (delete has a discarding and a decoding
  overload). Throws `APIError`: `.configuration`, `.network`, `.decode`,
  `.server(statusCode:message:)`.
- **`AuthManager.swift`** — `shared`, `ObservableObject`, `isLoggedIn`,
  `currentUser`, `nonisolated var token` (in-memory, Keychain-backed),
  `login(token:user:)`, `logout()`. Defines `UserInfo`.
- **`VersionGate.swift`** — checks `GET /api/v1/_version` at launch against this
  build's `CFBundleShortVersionString`. **Fails open**: only a provably-too-old
  client is blocked.
- **`UpdateRequiredView.swift`** — the blocking screen `VersionGate` shows.

## Verification

```bash
cd ios && xcodebuild -scheme GovaApp -sdk iphonesimulator \
  -destination 'platform=iOS Simulator,name=iPhone 16' test 2>&1 | tail -20
```

`GovaAppTests` holds unit tests; `GovaAppUITests` holds `SmokeTest.swift`, an
app-agnostic test that launches, taps every tab, and confirms a row push.

**The smoke test is not sufficient on its own.** It detects a push only
opportunistically and skips a resource whose list turns out to be read-only. So
**for each resource with a `detail` endpoint, add a UI assertion that tapping
its row opens a detail showing its data** — assert on a known field label or the
detail root's `accessibilityIdentifier`, then pop. This is a requirement: it is
what actually proves that resource's detail binds, which no build, unit test, or
grep can see.

## Device deploy

- **LAN http works by default** — `project.yml` ships an ATS
  `NSAllowsLocalNetworking` exception, so a physical iPhone can reach
  `http://<LAN-IP>:8080`. A non-local http host still needs the monolith's
  `/launch` https tunnel.
- **Signing:** `/prep` writes `DEVELOPMENT_TEAM` into `project.yml` so it
  survives `xcodegen generate`. Blank is fine for the simulator.
